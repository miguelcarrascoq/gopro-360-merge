# Privacy policy

**gopro-360-merge** does not collect personal data, analytics, or telemetry.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Optional network use (only when needed by the user-driven workflow):

- If `mp4-merge` is not already available (PATH, cache, or the release `tools\` folder), the app may download it once from the [gyroflow/mp4-merge](https://github.com/gyroflow/mp4-merge) GitHub Releases.
- Official self-contained release zips already bundle `mp4-merge`, so that download is not required for normal use of those builds.

No accounts, cloud sync, or advertising SDKs are included.
